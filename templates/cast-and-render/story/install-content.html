命令在哪里执行

打开 DSH Terminal，粘贴一行命令。

  1. 启动原版 DSH Desktop，在 Windows 任务栏右下角找到它的托盘图标（可能收在 ∧ 中）。
  2. 打开托盘菜单，选择 DSH Terminal，使用要安装插件的 Profile。
  3. 下载插件包，在组件卡片中填写保存目录，复制命令到终端并按 Enter。安装成功后保存工作并重启 Desktop。

这些命令在 Windows 的 DSH Terminal 中执行。下载路径有空格时保留双引号；无需切换到 WSL。

Windows 工作区

业务、Agent 和工具始终在 Windows。登录和选择连接环境在“AICO 信息 → 模型网关”；提供方与模型继续在原装“模型”页配置。安装并重启后，在“AICO 信息 → 插件信息”核对版本。使用本机模型无需配置 WSL；登录成功后还需进行实际模型请求验证。

可选

当需要通过 WSL 接入模型时，可以选择配置。选择你已配置好的 WSL 发行版与用户，各环境凭据独立保存。尚未准备 WSL 时先使用本机连接；网关准备与修复仍以对应版本说明为准。

安装说明

更新与常见问题。

安装后先完成一次简单任务；遇到问题可按下方提示检查。

已有插件，如何更新？

先保存工作并备份业务数据，查看目标版本的兼容说明。在原先的 DSH Terminal / Profile 中，使用新版本卡片生成的安装命令；完成后重启 Desktop 并核对版本。需要数据迁移的版本应先阅读该版说明，不直接降级覆盖。

浏览器助手常规更新无需重新配置，只有提示重新授权或连接修复时才处理。

如何卸载？数据会删除吗？

在安装该插件的 DSH Terminal 中，通过原装 dsh plugin remove <插件名> 卸载；插件名以安装登记为准。先卸载依赖 Harness 的业务插件，再卸载 Harness，完成后重启。卸载释放 AICO 自有服务与视图，保留原装插件、业务数据和其他用户配置；删除数据是另一个操作。

安装后没有入口，或任务无法运行？

先重启并核对“插件信息”里的登记版本，确认使用同一个 Profile。若提示资源缺失，按该版本资源说明处理；模型无回复时先检查原装“模型”页。不要在宿主目录自行运行 npm 或 pip 修复。

反馈问题 ↗：附上组件版本、Desktop 版本、失败步骤与错误信息，注明是否使用 WSL 模型连接；不要提交密码或令牌。

插件公开后，怎样执行安装命令？

从原版 Desktop 托盘打开 DSH Terminal，在当前 Profile 中运行 dsh plugin add "<下载包的完整路径>" --ignore-scripts。占位文字需换成真实下载路径；安装结束后保存工作并重启 Desktop。

WSL 需要安装另一套 Desktop 或业务插件吗？

不需要。WSL 只是 Windows 版 Harness 的可选模型通信方式，不是第三个插件平台。PPT、Profile、Wiki 和工具只在 Windows 运行。

授权会从 Windows 自动带到 WSL 吗？

不会。Windows 与每个 WSL 发行版/用户的模型凭据分别保存；在哪个环境登录，只在该环境生效。迁移旧版时也不复制或借用其他环境的凭据。

离线安装与旧版迁移现在可用吗？

通用离线交付和旧版数据迁移仍需单独验收。旧版 AICO 桌面包不能作为 AICO 2.0 插件安装。
