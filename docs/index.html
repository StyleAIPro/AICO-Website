04 / 上手指南

三步，装好你的工作台。

完整离线包内含桌面版与对应平台已发布的插件。
已有桌面版也可用同一离线包导入插件。

  1. 01

    下载完整离线包

    选择对应平台的完整离线包，解压后安装其中的 AICO 桌面版。已有桌面版可直接进行下一步。

  2. 02

    导入原始离线包

    在「设置 → 插件 → 插件商店」中选择「导入离线包」，选取下载的原始 .tar.gz 离线包。

  3. 03

    安装插件并重启

    选择当前平台可用的插件并点击安装，完成后重启 AICO。在「设置 → 模型」中配置所用模型，开始使用。

需要新版本时，请到 GitCode Release 查看发布说明并手动下载。
